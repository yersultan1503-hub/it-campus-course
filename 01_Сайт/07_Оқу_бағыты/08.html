Бүгінгі нәтиже

Оқу симуляторында өз кітабыңды қос, тізімді оқы, жылын өзгерт және сол жазбаны жой.

Кестедегі жол — жазба, баған — өріс. id жазбаны бірмәнді анықтайды. Браузер серверге сұрау жібереді; сервер SQLite қорымен жұмыс істеп, JSON қайтарады. HTML нәтижені көрсетеді, өзі деректер қоры емес. CRUD — қосу, оқу, өзгерту, жою. Кампуста CRUD оқу симуляциясы арқылы орындалады; нақты сервер іске қосылмайды.

CREATE TABLE books (
 id INTEGER PRIMARY KEY,
 title TEXT NOT NULL,
 year INTEGER
);
SELECT id, title, year FROM books;

Қолдау және бағалау

Симуляторда өз сынақ кітабыңызды қосыңыз. Тізімді оқып, сол кітаптың жылын өзгертіңіз; тек өз жазбаңызды жойыңыз.

Қиналсаң, ойындағы кеңесті аш немесе осы сабақтың мысалына қайта орал. Қосымша ойындар — ерікті.

Мұғалім зертхананы 6 балға, екі ойын нәтижесін 2 балға, рефлексияны 2 балға бағалайды. XP — ойын ұпайы, сабақ бағасы емес.

Ойын ашылмаса, осы миссияны мұғалімнің көрсетуімен орындап, нәтижені рефлексияда сипатта. Қосымша тапсырма берілмейді.
