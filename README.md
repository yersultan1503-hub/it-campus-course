`03_ҚМЖ` және `Презентациялар_және_видео` — негізгі папкаларға сілтемелер. ZIP арқылы жүктегенде олар папка болып ашылмаса, жоғарыдағы нақты жолдарды пайдаланыңыз. Git тарихында ойын папкасының Unicode жазылуы екі түрде кездеседі; осы README-дегі **02_Ойын_коды** сілтемесін қолданыңыз. Бұл құжаттарды реттеу кезінде бастапқы код папкалары өшірілген жоқ.

## Оқу реті және деректер

8 біріктірілген сабақ × 45 минут: теория → презентация → бейне → 3D миссия → рефлексия. Бұл жеке статикалық курстағы ойын прогресі браузерде сақталады; оқушы есебін Classroom-ға тапсырады. Жылдық курстың Google кіруі, ортақ базасы мен мұғалім журналы бөлек жобада орналасқан.

## Жергілікті ашу

Жоба түбірінде:

```sh
python3 -m http.server 8878 --directory 01_Сайт --bind 127.0.0.1
```

Ашу: http://127.0.0.1:8878/ . Ойын бастапқы кодында `npm ci`, `npm run dev`; дайын жинақ үшін `npm run build`. Қайта жиналған ойын ғана `01_Сайт/game` ішіне енгізіледі.

**Жариялау нысаны: `it-club-10-course`; жарияланатын папка: `01_Сайт`.** Репозиторийдің түбірін түгел жарияламаңыз: мұғалім жауаптары мен қызметтік файлдар бар.

## Екі жобаны бөлек ашу

Бір папкада тармақтарды ауыстырғаннан гөрі екі бөлек жұмыс көшірмесін пайдаланыңыз. Жеке репозиторийге рұқсаты бар GitHub аккаунты қажет.

```sh
git clone --branch main --single-branch https://github.com/yersultan1503-hub/it-campus-course.git IT_CAMPUS_Q3
git clone --branch year-course-pilot --single-branch https://github.com/yersultan1503-hub/it-campus-course.git IT_CAMPUS_YEAR
```

- III тоқсан жұмысы: **IT_CAMPUS_Q3**.
- Жылдық сайт пен қалашықтар: **IT_CAMPUS_YEAR**.
- Өзгеріс алдында `git branch --show-current` және `git status` арқылы орынды тексеріңіз.
- Екі тармақты тұтас merge етпеңіз: олардың құрылымы мен сервері бөлек. Қажет материалды жеке көшіріп, жылдық курстағы рұқсат және сабақ ретімен сәйкестендіріңіз.
- GitHub-қа сақтау мен сайтты жариялау — бөлек әрекеттер. Жариялау алдында нақты Vercel жобасын тексеріңіз.
