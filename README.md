# IT CAMPUS

10-сынып ЖМБ информатика курсы: 8 сабақ × 45 минут, 3D кампус, авторлық бейнелер және ҚМЖ.

Сайт: https://it-club-10-course.vercel.app

## Құрылымы

- `01_Сайт/`: жариялауға дайын статикалық сайт, сегіз бейне, презентациялар, көрнекіліктер, Word/PDF ҚМЖ және дайын ойын.
- `02_Ойын_коды/`: React, Vite, Three.js ойын коды, модельдер, лицензиялар және тесттер.
- `03_ҚМЖ`: `01_Сайт/qmj` папкасына салыстырмалы сілтеме.

## Жергілікті іске қосу

Статикалық сайт: `python3 -m http.server 8878 --directory 01_Сайт --bind 127.0.0.1`, содан кейін http://127.0.0.1:8878 ашыңыз.

Ойын кодын өңдеу үшін `02_Ойын_коды` ішінде `npm ci`, кейін `npm run dev`. Дайын нұсқаны құрастыру: `npm run build`; нәтиже `dist/client` ішінде болады. Өзгертілген ойын осы сайттың `01_Сайт/game` папкасына көшіріледі.

Vercel-ге тек `01_Сайт` папкасын жариялау керек. Аккаунт кілттері және `.vercel` байланыс деректері репозиторийге кірмейді.

## Медиа және лицензиялар

Сегіз авторлық бейне `01_Сайт/media/01_video.mp4`–`08_video.mp4` ішінде. Презентациялар сол media папкасында. Кейіпкер модельдерінің лицензиялары мен атрибуциясын ойынның public/assets ішіндегі CREDITS және лицензия файлдарынан қараңыз; оларды сақтаңыз.

## Оқу реті

Теория → презентация → бейне → 3D миссия → рефлексия. Оқушының прогресі сол браузерде сақталады. Мұғалімге нәтиже автоматты жіберілмейді: оқушы TXT есебін Classroom-ға өзі тіркейді.
