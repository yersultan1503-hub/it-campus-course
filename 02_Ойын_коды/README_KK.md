# IT CAMPUS — 3D оқу әлемі

10-сынып информатикасына арналған ойнатылатын жергілікті жоба. Нақты WebGL кеңістігі, қозғалатын оқушы кейіпкері, Байт роботы, сегіз оқу ғимараты және әр тақырыпқа бес ойын түрі бар.

## Ойынды ашу

Windows-та архивті толық шығарып, `Start_Game.cmd` файлын екі рет басыңыз. Ойын `http://127.0.0.1:4176/` мекенжайында ашылады. Сервер терезесін ойын кезінде ашық қалдырыңыз; жабу үшін Ctrl+C. Осы компьютердегі Codex Node.js қолданылады; басқа компьютерде Node.js 22+ қажет. Дайын жинақ архивте бар, ойнау үшін npm install қажет емес. index.html файлын тікелей ашу орнына іске қосқышты пайдаланыңыз.

Әзірлеу: `pnpm install`, `pnpm dev --host 127.0.0.1 --port 4175`.
Жинақ: `pnpm build`. Жинақтан кейін тексеру: `pnpm test:sites`.

## Сабақтағы 5–10 минут

1. 0:00–0:30 — мұғалім бүгінгі тақырыпты атайды; оқушы сол ғимаратты немесе «Аймақтар» мәзірін ашады.
2. 0:30–2:30 — «Білім аренасы»: үш сұрақ, жауапқа түсіндірме.
3. 2:30–4:30 — «Жұбын тап»: төрт ұғымды сәйкестендіру.
4. 4:30–7:30 — «Код шебері», «Қате детективі» немесе «Сынақ зертханасы».
5. 7:30–9:00 — нәтижені қарап, бір шешімді ауызша түсіндіру; қажет болса есепті жүктеу.

Кез келген үш түрлі ойын аяқталса, тақырып миссиясы орындалады. Бір ойынды алғаш аяқтау +60 XP, қайталау қосымша ұпай бермейді. Барлық сегіз тақырыпты бір сабақта өту қажет емес. Уақыт — жоспарлық бағалау, сыныппен нақты сынаудан кейін бейімделеді. Қатаң таймер жоқ.

## Сегіз тақырып

| № | Тақырып | Тәжірибелік әрекет |
|---|---|---|
| 1 | HTML негіздері | Тақырып, абзац, үш мақсаттан тұратын тізім |
| 2 | Кестелер және графика | 3×3 дерек кестесі, alt, сурет ені |
| 3 | Сілтемелер және шағын сайт | href пен id сәйкестігі |
| 4 | CSS және бейімделетін макет | 900px row, 500px column |
| 5 | Аудио, бейне және субтитр | Екі уақыт аралығындағы қазақша субтитр |
| 6 | JavaScript және енгізуді тексеру | Бос жол, бос орын, дұрыс ат және trim() |
| 7 | Интерактивті жоба және тестілеу | Жауап кілтін жөндеу, төрт тест жағдайы |
| 8 | Веб-бет және деректер қоры | CREATE, READ, UPDATE, DELETE оқу симуляциясы |

Барлығы 40 тақырыптық ойын әрекеті: арена, сәйкестендіру, код жинау, қате жөндеу, зертхана. Бұл белгілі платформалардың көшірмесі немесе олардың ендірілген ойындары емес; осы жобаға жасалған өз ойын механикалары.

## Басқару

- WASD / ЦФЫВ немесе бағыттау пернелері — кейіпкерді жүргізу. Пернені алғаш басқанда ойын бірден басталады; қысқа басу да қадам жасайды. Бағыт камераға қатысты есептеледі. «Сен» белгісі өз кейіпкеріңді көрсетеді. Жерді басу — сол бағытқа жүру; кедергілерді айналып өту қажет.
- Ғимараттағы белгі — тақырып ойындарын ашу. Ғимараттың өзін басу — тақырыпты таңдау.
- E — жақын аймаққа кіру; M — барлық аймақтар; Escape — терезені жабу.
- Басып тұрып сүйреу — камераны 360° айналдыру; Shift + сүйреу немесе оң батырмамен сүйреу — жылжыту. Тачпадта екі саусақпен сырғыту — көріністі жылжыту; қысу немесе Ctrl + сырғыту — масштаб. «Камера» мәзірінде бұрылу, жоғары/төмен қарау, +/− және «Бастапқы көрініс» батырмалары бар.
- Телефонда жерді және аймақ белгілерін түртуге болады; оқу тапсырмалары тар экранға бейімделген. Негізгі мақсатты құрылғы — мектеп компьютері.
- Баптауларда жеңіл графика, қозғалысты азайту, дыбыс, лақап ат және прогресті тазарту бар.

## Нәтиже және шектеулер

Прогресс тек сол браузердегі localStorage ішінде сақталады. «Жетістіктер» ішінен JSON есеп жүктеледі; мұғалімге оқушы өзі береді. Бұл автоматты баға емес. Жеке ойын режимі іске асырылған; онлайн сынып бөлмелері мен ортақ рейтинг әзірге жоқ.

HTML редакторы нақты HTML-ді талдап, оқшауланған iframe ішінде көрсетеді; JavaScript енгізу және CSS орналасу тәжірибелері жұмыс істейді. Медиа зертханасы — уақыт пен субтитрдің оқу симуляторы, нақты бейнефайл емес. CRUD зертханасы — жадыдағы модель, нақты SQLite не сервер қосылмаған; бұл интерфейсте көрсетілген. Редактордың iframe ішінде JavaScript орындалмайды.

Жоба көпшілікке жарияланбаған. Қаріп интернеттен жүктелмесе, Arial қолданылады. Құпиясөздер мен Classroom тіркелгі деректері жобаға енгізілмеген.

## Орындалған жұмыс жоспары

1. Жарқын 3D кампус көркем бағытын таңдау және жаңа ойын көрінісін дайындау.
2. WebGL кампус, сегіз ғимарат, кейіпкер, жүретін NPC, робот, камера және қозғалыс жасау.
3. Әр тақырыпқа бес механизмнің тапсырмаларын енгізу.
4. Қазақша кері байланыс, кеңес, жеңіс, XP және жергілікті сақтау қосу.
5. Браузерде негізгі оқу жолын, тар экранды және жинақты тексеру.

Көрнекі референстің бағыты сақталған; ойын ішіндегі 3D модельдер нақты рендерленетін жеңіл стильде жасалған. Скриншотты фон ретінде көрсетпейді.

Қадам анимациясы жүрілген қашықтыққа байланысты: тізе мен тобық бүгіліп, аяқ кезек көтеріледі. «Қозғалысты азайту» ойыншының негізгі жүру анимациясын сақтайды, фондық NPC саяхаты мен сәндік қозғалысты шектейді.
