01 / ТҮСІНУ · 0–10 МИН

Алдымен тақырыпты түсініп ал

Бүгінгі нәтиже

Тесттің жауап кілтін түзет; жауап жоқ, қате, дұрыс және қайта тексеру жағдайларын сына.

Дайын жоба HTML мазмұнын, CSS макетін және JavaScript әрекетін біріктіреді. Бірдей name мәні бар радиоэлементтер бір топқа кіреді. :checked таңдалған жауапты табады. Тест есебінде әрекет, күтілетін нәтиже, нақты нәтиже және түзету жазылады.

const feedback = document.getElementById("out");
const selected = document.querySelector("input[name=q]:checked");
const key = "html"; // Дұрыс жауаптың value мәні
if (!selected) {
 feedback.textContent = "Жауап таңдаңыз";
} else {
 feedback.textContent = selected.value === key
  ? "Дұрыс!" : "Қайта ойланыңыз";
}

Қолдау және бағалау

Бір сұрақтың радиоэлементтерінде name бірдей болсын. Дұрыс жауаптың value мәні key мәнімен сәйкес келуі керек.

Қиналсаң, ойындағы кеңесті аш немесе осы сабақтың мысалына қайта орал. Қосымша ойындар — ерікті.

Мұғалім зертхананы 6 балға, екі ойын нәтижесін 2 балға, рефлексияны 2 балға бағалайды. XP — ойын ұпайы, сабақ бағасы емес.

Ойын ашылмаса, осы миссияны мұғалімнің көрсетуімен орындап, нәтижені рефлексияда сипатта. Қосымша тапсырма берілмейді.
