trim() қолданып, бос жолды, тек бос орындарды және дұрыс атты сына.

getElementById элементті id бойынша табады. addEventListener click оқиғасына әрекет тіркейді. input.value өрістің мәнін береді, trim шеткі бос орындарды жояды. textContent нәтижені қауіпсіз мәтін ретінде көрсетеді. Браузердегі тексеріс сервердегі тексерісті алмастырмайды.

const nick = document.getElementById("nick");
const msg = document.getElementById("msg");
document.getElementById("join").addEventListener("click", () => {
 const name = nick.value.trim();
 if (!name) { msg.textContent = "Лақап ат енгізіңіз"; return; }
 msg.textContent = "Қош келдіңіз, " + name;
});

Қолдау және бағалау

trim() белгісін қосқан соң үш үлгіні кезекпен тексеріңіз: бос жол, үш бос орын және дұрыс ат.

Қиналсаң, ойындағы кеңесті аш немесе осы сабақтың мысалына қайта орал. Қосымша ойындар — ерікті.

Мұғалім зертхананы 6 балға, екі ойын нәтижесін 2 балға, рефлексияны 2 балға бағалайды. XP — ойын ұпайы, сабақ бағасы емес.

Ойын ашылмаса, осы миссияны мұғалімнің көрсетуімен орындап, нәтижені рефлексияда сипатта. Қосымша тапсырма берілмейді.
