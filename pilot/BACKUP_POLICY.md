# Сақтау тәртібі

Жылдық пилот: GitHub `yersultan1503-hub/it-campus-course`, `year-course-pilot` тармағы. Бұрынғы main және Desktop/IT_CAMPUS өзгертілмейді.

Әр тексерілген өзгерістен кейін жеке commit, remote SHA мен файл тізімі салыстырылады. GitHub расталмайынша жалғыз жергілікті файл жойылмайды. Автоматикалық уақыттық тапсырма жоқ: бұл әр өңдеу сессиясының аяқталу тәртібі.

Git құрамына бастапқы код, тесттер, құрастыру нұсқауы және активтер кіреді. data/, .env, OAuth кілттері, нақты оқушы деректері, жергілікті сынақ парольдері, node_modules кірмейді. GitHub — код сақтайтын орын; оқушылардың ортақ базасы емес.

Тазалау: тек қайта құрастырылатын кештер, ескі build bundle-дары және дәл SHA бойынша қайталанған уақытша көшірмелер. Қазіргі іске қосылған build, авторлық бейне, лицензия файлдары, оқу материалдарының жалғыз көшірмесі және база сақталады.

Қалпына келтіру: pilot/requirements.txt тәуелділіктерін орнату, жеке Google server баптауын қайта қосу; game-source ішінде npm ci және npm run build; dist/client ішін pilot/public/game ішіне көшіру. Сервер қазір тек жергілікті 127.0.0.1:8890 адресіне арналған.
