# Жылдық сайт және сервер

[← Жылдық жобаның басты беті](../README.md) · [Ойын коды](../game-source/README.md)

**Сайт: https://it-campus-year-course.vercel.app/**

Бұл `year-course-pilot` тармағындағы жылдық курстың сервері. `pilot` атауы тарихи сақталған. Production сайт ортақ Supabase базасын қолданады; SQLite тек бөлек жергілікті әзірлеу үшін қолданылады.

## Негізгі файлдар

| Жол | Мақсаты |
|---|---|
| `public/index.html`, `public/app.js`, `public/*.css` | Сайт интерфейсі |
| `app.py` | HTTPS / FastAPI кіру нүктесі, cookie, API және материалдарға рұқсат |
| `server.py` | Google кіруі, рөлдер, сабақ рұқсаттары, прогресс пен баға |
| `postgres_store.py` | Ортақ Postgres базасымен жұмыс |
| `course_catalog.json` | Сабақтар каталогы және ресурс сілтемелері |
| `course_content.py`, `materials/extended-content.json` | Түсіндірмелер мен тапсырмалар |
| `public/resources/` | ҚМЖ және оқу файлдары; production-да сервер рұқсатымен беріледі |
| `public/game/` | Жылдық ойынның дайын жинағы; бастапқы код `../game-source` ішінде |
| `public/legacy-q3/` | Жылдық курсқа кіріктірілген III тоқсан нұсқасы |
| `database/` | База сызбасы, рұқсат саясаты және сертификат |

## Оқу мазмұны

Каталогта I тоқсан — 15 жазба (12 оқу, 3 бағалау), II тоқсан — 14 модуль, III тоқсан — 8 біріктірілген сабақ, IV тоқсан — 10 модуль. Каталог пен файлдар тізімін өзгеріс кезінде қайта тексеріңіз.

II/IV тоқсан жоспары — №399 бұйрықтың 108-қосымшасына сәйкестендірілген авторлық жоспар; мектеп бекіткен КТЖ емес. БЖБ/ТЖБ уақытын мұғалім/мектеп анықтайды. Ресми дереккөздер, оқу мақсаттарындағы сәйкестендіру мәселелері: [materials/legal/README.md](materials/legal/README.md).

II–IV тоқсан ҚМЖ файлдары бар. Құжат ішіндегі сілтемелерді жеке тексеріңіз: бұрын жасалған ҚМЖ-да жергілікті мекенжай қалуы мүмкін; сайттың жариялануы DOCX/PDF ішіндегі мәтінді автоматты өзгертпейді. Сыртқы материалдар автор сілтемесімен беріледі, сыртқы ойын ұпайлары журналға автоматты түспейді.

## Бағалау және аккаунттар

- Сервер дұрыс жауап үлесінен 0–10 автоматты балл есептейді. Қазіргі тексеру — таңдаулы сұрақтар; Python/SQL кодын орындап бағалау енгізілмеген.
- Мұғалім бағасы бөлек сақталады; қойылса, қорытындыда сол қолданылады, оның ішінде 0 балл да. Бұл ресми тоқсандық баға емес.
- Баға қою мен сабақты мақұлдау бөлек. Оқушыға келесі сабақтың ашылуын сервер шешеді; ойынның жергілікті XP-і рұқсат бермейді.
- Мұғалім өз сыныбын, әкімші барлық рұқсат етілген оқушыларды қарайды. Мұғалім/әкімшіге курс ресурстары ашық.
- Google кіруі қолданылады. Google паролі сайтқа алынбайды, әкімшіге көрсетілмейді. Жалған аккаунттармен кіру production-да өшірулі.
- Мұғалім рөліне өтінішті әкімші бекітеді. Рөл ауыстыру, сессияны жабу, қолжетімділікті жабу/қайтару аудитке жазылады.
- Жаңа құрылғыдан кіру расталғанда бұрынғы сервер сессиясы жабылады. Бір браузердегі беттер ортақ сессияны пайдаланады.

## Жергілікті әзірлеу

Python 3.12 ортасын қолданыңыз. Осы папкада:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python server.py --port 8890
```

Ашу: http://127.0.0.1:8890/ . Жергілікті SQLite деректері production базасына автоматты көшпейді. Нақты Google кіруі үшін сервердің жеке баптауы қажет. Production құпияларын тест ортасына көшірмеңіз.

```sh
.venv/bin/python -m unittest discover -s tests -v
```

## Жариялау

Жоба түбірінен:

```sh
python3 pilot/scripts/prepare_cloud_release.py
```

Нәтиже: `year-cloud-release/`. Дайын папка **it-campus-year-course** Vercel жобасына арналған. Скриптте осы жоба идентификаторы бар; басқа жобаға қолданар алдында тексеріңіз. Репозиторийдің түбірін немесе `public` папкасын түгел ашық статикалық сайт ретінде жариялау жарамайды: кейбір материалға серверлік рұқсат қажет.

Сервер баптаулары: `CAMPUS_DATABASE_URL`, `CAMPUS_ORIGIN`, `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `GOOGLE_REDIRECT_URI`. Мәндері GitHub-та сақталмайды. Production callback: https://it-campus-year-course.vercel.app/api/auth/google/callback . Толығырақ: [CLOUD_DATABASE.md](CLOUD_DATABASE.md).
