## Дайын оқу жолы

Сабақ → презентация/PDF және бейне → 3D зертхана → серверлік тексеру → қысқа таңдау рефлексиясы → мұғалім журналы → мұғалім мақұлдаса келесі сабақ. I тоқсанның 15 жазбасы (12 оқу сабағы, 3 бағалау) және III тоқсанның 8 сабағы қосылды. II және IV тоқсан импортталмаған.

Профиль аты сервер базасында сақталып, мұғалім мен әкімшіге көрінеді. Күн/түн таңдауы осы браузерде сақталады. Бағалау тапсырмаларының оқушы PDF нұсқалары бөлек; жауап кілттеріне тікелей сілтемемен кіруде де мұғалім/әкімші рөлі тексеріледі. Барлық нәтиже әзірге жергілікті SQLite базасында; Supabase синхрондауы әлі қосылмаған.

## Тіркелу — соңғы шешім

2026-11-08: пайдаланушы телефон/SMS талабын **Google аккаунтымен кіруге** ауыстырды. SMS қолданылмайды. Бір Google `sub` идентификаторына бір профиль; email бірегей; жаңа оқушы рөлі серверде беріледі. Google паролі алынбайды, сақталмайды және әкімшіге көрсетілмейді. Әкімші email-ді көреді және сессияны жабады. Қалпына келтіру Google арқылы.

Google OAuth дайындалған: state/cookie байланысы, бір реттік state, PKCE, nonce, google-auth арқылы ID token signature/audience/issuer/expiry тексеруі, email_verified. Google Cloud OAuth client бапталды; нақты аккаунтпен кіру браузерде тексерілді. Қазір тек loopback local pilot; production HTTPS және тұрақты сервер/базаға көшіру бөлек міндет.

Бір аккаунтта бір серверлік сессия. Жаңа құрылғыдан кіруді растағанда ескі сессия жарамсызданады. Бір браузердің бірнеше беті бір сессияны бөліседі. Бұл аппараттық fingerprint емес. API ескі сессиямен нәтиже тапсыруды қабылдамайды; экранда бұрын ашылған мәтінді қашықтан өшірмейді.

## Аккаунт басқару — 2026-11-08

Жалған аккаунттар мен парольмен кіру өшірілген. Тек Google. Оқушы профильден мұғалім рөліне өтініш береді; әкімші оны қабылдайды не түсініктемемен бас тартады. Әкімші student/teacher рөлін ауыстырады, қолжетімділікті жабады/қайтарады және сессияны жабады. Әр өзгеріс audit кестесіне жазылады. Әкімші өзін бұғаттай алмайды, екінші admin жасауға сервер де, базаның unique индексі де жол бермейді.

Жобадан шығару — active=0 және барлық session/pending login токендерін жою. Оқу жұмыстары сақталады, сол Google аккаунтымен қайта кіру бұғатталған. Қолжетімділікті тек әкімші қайтарады. Тесттер тек уақытша базада өтеді.
