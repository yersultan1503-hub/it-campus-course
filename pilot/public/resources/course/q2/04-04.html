4. Мини-жоба: баға жүйесі

Үш бағаның орташа мәнін есептеп, деңгейін анықтайтын екі функция жаз: average() және grade().

def average(a, b, c):
    return (a + b + c) / 3

def grade(avg):
    if avg >= 90:
        return "Жоғары"
    elif avg >= 70:
        return "Орта"
    return "Төмен"

avg = average(95, 82, 88)
print(avg, grade(avg))

5. Декомпозицияға тапсырма

Интернет-дүкен есебін 3 функцияға бөл:

1) тауарлар сомасы; 2) жеңілдік; 3) соңғы төлем.

def subtotal(a, b, c):
    return a + b + c

def discount(total, percent):
    return total * percent / 100

def final_price(total, disc):
    return total - disc

s = subtotal(3000, 4500, 2500)
d = discount(s, 10)
print(final_price(s, d))
