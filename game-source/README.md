# Жылдық курс · ойынның бастапқы коды

[← Жылдық жоба](../README.md) · [Сайт / сервер](../pilot/README.md)

Бұл ойын **https://it-campus-year-course.vercel.app/** жылдық сайтына арналған. III тоқсанның жеке курсын өзгерту үшін [main тармағын](https://github.com/yersultan1503-hub/it-campus-course/tree/main) пайдаланыңыз.

## Жұмыс реті

1. Осы папкадағы [AGENTS.md](AGENTS.md) нұсқауларын оқыңыз.
2. `npm ci` арқылы тәуелділіктерді орнатыңыз.
3. `npm run dev` — көріністі әзірлеу. Vite серверінің өзі оқушы аккаунты мен прогресін сақтамайды; интеграциялық тексеру сайт серверімен бірге жасалады.
4. `npm run build` — жинақты құрастыру; `dist/client` нәтижесін тексеріңіз.
5. Дайын жинақты жылдық сайттың `pilot/public/game/` папкасына енгізіп, сайтпен бірге тексеріңіз. Құрастыру өздігінен Vercel-ге жарияламайды.

`npm run test:sites` — пакеттегі Sites worker тесті; ол барлық педагогикалық және рұқсат сценарийлерінің толық тексерісі емес. Қосымша тесттер `tests/` ішінде.

## Интеграция ережелері

- Сабақ рұқсаты, баға және прогресс серверден алынады. Клиент XP-і келесі сабақ ашуға негіз болмайды.
- Google сессиясы және API сайтпен бір origin-де жұмыс істеуі керек.
- II тоқсанға 14 зертханалы канал қалашығы және KayKit анимациялары енгізілген. Басқа тоқсандарды өзгерткенде олардың жеке көріністерін сақтаңыз.
- III тоқсанның кіріктірілген нұсқасы: [integration/README.md](integration/README.md). Ондағы ескі жергілікті абсолют жолдар тарихи контекст; осы репозиторийдегі `pilot/public/legacy-q3` және `pilot/legacy-game-source` жолдарын негізге алыңыз.
- Құрастырылған файлды ғана өңдемеңіз: бастапқы кодты өзгертіп, қайта жинаңыз. Модель лицензиялары мен автор көрсетілімдерін сақтаңыз.
- `archives/IT_CAMPUS_Q3` — архив; жылдық ойынның негізгі коды емес.
